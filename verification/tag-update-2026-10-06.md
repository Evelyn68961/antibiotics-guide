# New tag options and tagging (2026-10-06)

Items that previously had no multi-select option were written into Notes. On 2026-10-06 the options below were added to the database, and each page was re-tagged by an agent that read the page and its verification report. Tags were added only where the page's label- or guideline-sourced text supports them. Existing tags were kept.

## Options added

- **Coverage:** Moraxella, Citrobacter, Treponema, Borrelia, Rickettsia, C. difficile, Nocardia, H. pylori, Protozoa, Cryptococcus, Mucorales, Endemic fungi, Pneumocystis, CMV, SARS-CoV-2
- **Indications:** URTI, AECB, STI, Syphilis, H. pylori, Bone & joint, Cryptococcosis, Mucormycosis, PJP, Antifungal prophylaxis, Protozoal infection, CMV, COVID-19
- **Side Effects:** CDAD, tooth discoloration, serotonin syndrome, myasthenia exacerbation, hyperkalemia, hyponatremia, hypernatremia, hypomagnesemia, arrhythmia, aortic aneurysm, heart failure, tendinopathy, lactic acidosis, AGEP, hypersensitivity, infusion reaction
- **Monitor:** glucose, TDM, hearing, eye exam

## Two corrections

- **"Osteoarthritis" → "Bone & joint"** on every page that had it. The tag was being used for bone and joint infection; osteoarthritis is a non-infectious disease. The old option is still in the schema, unused, so the owner can delete it.
- **Remdesivir:** "Pneumonia" removed (its labelled indication is COVID-19), COVID-19 and SARS-CoV-2 added.

## Removed again after review

TDM was removed from acyclovir, metronidazole, oxacillin, piperacillin/tazobactam, cefotaxime and tetracycline: their pages advise drug levels only in specific situations (ICU, CRRT, neonates, severe renal or hepatic impairment), not routinely. Lactic acidosis was removed from anidulafungin (it applies only to hereditary fructose intolerance).
