# The Antimicrobial Apothecary · 抗菌魔法藥櫥

A whimsical witch's-cupboard view of clinical antimicrobial dosing and
coverage. Each drug is a powder jar on a candlelit shelf, with curios
(skulls, crystal balls, mushrooms, eye-jars) keeping them company.

## What it does

- **Search** by brand name (e.g. *Cubicin*) or generic name (e.g.
  *Daptomycin*)
- **Filter** by category (Carbapenem, Cephalosporin, …), indication
  (UTI, HAP, Meningitis, …), or coverage (MSSA, MRSA, ESBL organisms, …)
- **Click any jar** to open a parchment-style monograph: adult /
  pediatric / renal / hepatic dosing, pregnancy and breastfeeding notes,
  mechanism, drug interactions, side effects, and monitoring
- **Hover any abbreviation tag** (CAP, FN, MSSA, …) to see the full
  English term
- **Practice questions** auto-generated from each drug's data so you can
  self-quiz on coverage, indications, class, renal adjustment, and
  pregnancy use
- **Bilingual UI** (English / 繁體中文) — toggle in the top-right.
  Drug names, organism names, and clinical abbreviations are kept in
  their international forms in both languages; only the surrounding UI
  shell is translated.

## Status

Work in progress — data is for educational reference only, not for
clinical decision-making.
